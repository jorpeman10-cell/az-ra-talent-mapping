# 外部顾问评估 P2a 实施计划（网关接入 + HR 面评页）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 外部顾问评估接入意图网关——3 个 candidate.* capability packs（intake 建档+双链接 / assess 定级定薪 / narrative 叙事素材），零 LLM 正则路由 + 确认卡 + 严格 wire 卡片 + 黄金契约；服务侧补 HR 面评表单页（替代原设计的第 4 个对话包）。

**Architecture:** 状态机全部在 headhunt-svc（网关执行无状态、单轮）。executor 经 urllib HTTP 调 `HEADHUNT_API`（绝不 in-process 调 MCP），模式完全镜像现有 headhunt/ 四包。设计文档 §5.1 的 4 包改为 3 包 + HR 表单页（原因：网关签名确认单轮固定 slots，结构化面评问卷无法可靠对话收集）。

**Tech Stack:** Python（federation_gateway，urllib+dataclass，pytest）、headhunt-service（FastAPI）、Lobe TS 侧**不在本计划**（P2b 单独计划，基于本计划冻结的黄金卡契约开发）。

**前置依赖：** ① P1 已合入 workspace main（66a43ec+）；② 生产部署 P1 后网关才有真实下游（开发期用 FakeClient + 本地服务，不阻塞）；③ Task 1 建 worktree 时若 canary 已前进，从最新 canary 拉。

  - `CandidateAssessExecutor`（kind `candidate_assess_result`，key `candidate_assess`）：`{subject}` → resolve → POST `/api/candidate/{cid}/assess` → wire `{kind, schema_version:"candidate-assess-card-v1", cid, name, status, grade, base_grade, effective_billing_wan, verify_coefficient, band:{p25,p50,p75,source,confidence}, breakeven_wan, npv_quick_at_target, top_line, top_overlap_pct, divergent:[..], high_divergence, rationale:[..], warnings:[..]}`（band 可能全 null——no_internal_data 时保留 source/confidence，数值键为 null）
  - `CandidateNarrativeExecutor`（kind `candidate_narrative_result`，key `candidate_narrative`）：`{subject}` → resolve → GET `/api/candidate/{cid}` + GET `/api/template` → wire `{kind, schema_version:"candidate-narrative-card-v1", cid, name, status, grade, confidence, top_line, divergent:[..], high_divergence, open_notes:[{role, dimension, question, answer}...≤12]}`——open_notes 取两份问卷的 text 题原文（qid→label 用 template 映射），供 Agent 叙事引用
  - 三执行器均：`enterprise_user_id` 空 → `{kind, error:"enterprise_user_required", schema_version}` 且 `client.calls == []`；`subject` 缺失 → `error:"subject_required"`；服务 409（问卷不齐）→ `{kind, error:"questionnaires_incomplete", schema_version}`；404/歧义 → `error:"candidate_not_found"` / `error:"ambiguous_subject"` + `candidates`
- 卡片整形用 `_pick` 白名单 + `_CARD_SCHEMA_VERSIONS` 盖章，全部镜像 `capability_runtime/headhunt/executor.py` 的实现（实现者先读该文件再动笔）
